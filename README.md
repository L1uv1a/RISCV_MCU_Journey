\# Vivado FPGA Project

RISCV Microcontroller from Scratch



\## Description

FPGA design created using AMD/Xilinx Vivado ML Edition.



\## Tool Version

Vivado 2025.2 ML Standard Edition



\## Project Structure

\- srcs/        : HDL sources

\- constraints/ : XDC files

\- ip/          : IP configuration

\- scripts/     : build scripts (optional)



\## How to Open

1\. Launch Vivado

2\. Open .xpr project file



\## How to Build

Run:

\- Synthesis

\- Implementation

\- Generate Bitstream



\## Notes

Auto-generated folders are excluded using .gitignore.

Project can be rebuilt from sources.
